# Andrei Dashkevich — AI Engineer

Исходники сайта: английский по умолчанию, русский по переключателю EN / RU.
Светлая и тёмная темы. Без сборки и npm-зависимостей.

## Локальный запуск

Откройте папку в Cursor / VS Code. Из корневой папки выполните:

    python3 -m http.server 8000 --directory dist

Откройте http://localhost:8000
На Windows можно использовать `python` вместо `python3`.

## Файлы

- dist/index.html — разметка и английский текст по умолчанию.
- dist/style.css — дизайн, адаптивная вёрстка и темы.
- dist/i18n.js — словарь переводов и переключение языка.
- dist/app.js — интерактивность, RAG-демо и форма связи.
- .openai/hosting.json — конфигурация существующего сайта в Sites.

Форма создаёт mailto-письмо: посетитель отправляет его из своего почтового приложения.
Google Fonts требует интернет-соединения; при недоступности используется системный шрифт.
Для независимого размещения можно загрузить содержимое dist/ на любой статический хостинг.
Изменения этой локальной копии автоматически не обновляют опубликованный сайт в Sites.
